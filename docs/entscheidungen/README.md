# Entscheidungen

Kurze Notizen zu Entscheidungen, die schwer rückgängig zu machen sind. Jede beantwortet drei
Fragen: Was war die Lage, was haben wir entschieden, was heißt das für später.

Wer eine Entscheidung ändert, schreibt eine neue Datei und verweist auf die alte, statt die alte
umzuschreiben. Sonst geht verloren, warum es einmal anders war.
